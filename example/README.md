# Приклад використання `gemini-webapi-manager` (Example)

Цей проєкт демонструє, як інтегрувати та використовувати бібліотеку `gemini-webapi-manager` у реальному додатку Python, а також надає зручне консольне меню для інтерактивного ручного тестування всіх можливостей бібліотеки.

---

## Можливості прикладу

1. **Еталонний код інтеграції:** показує правильні патерни роботи з `AccountManager`, обробки помилок, контекстних менеджерів та `ManagedChat`.
2. **Консольне меню:** інтерактивне керування слотами, логіном, лімітами, проксі та відправкою запитів.
3. **Діалоговий чат:** збереження контексту бесіди з Google Gemini через `client.start_chat()`.
4. **Ізольоване сховище:** за замовчуванням `vault.bin` зберігається у локальній підпапці `./data/`, що спрощує перевірку, резервне копіювання та передачу на сервер.

---

## Швидкий старт

### 1. Створення та активація віртуального середовища

Перейдіть у папку `example`:

```bash
cd example
python -m venv .venv
```

Активація на Windows (PowerShell):
```powershell
.\.venv\Scripts\Activate.ps1
```

Активація на Linux / macOS:
```bash
source .venv/bin/activate
```

### 2. Встановлення залежностей

Залежності встановлюються з GitHub-репозиторію `CatDogFishFrog/gemini-webapi-manager`:

```bash
pip install -r requirements.txt
```

> **Примітка щодо браузерів:** для первинного входу (Google Login) бібліотека використовує встановлений у системі Google Chrome або Microsoft Edge. Якщо вони відсутні, встановіть Playwright Chromium:
> ```bash
> playwright install chromium
> ```

### 3. Налаштування змінних середовища (`.env`)

Скопіюйте зразок конфігураційного файлу:

```bash
cp .env.example .env
```
(на Windows: `copy .env.example .env`)

Параметри у файлі `.env`:

```env
# Ключ шифрування (мінімум 16 символів)
GEMINI_MANAGER_KEY="your-secret-vault-key-min-16-chars"

# Шлях до папки сховища vault.bin (за замовчуванням ./data поруч із main.py)
GEMINI_MANAGER_HOME="./data"

# Кількість слотів
GEMINI_MANAGER_MAX_SLOTS="10"
```

Якщо у вас ще немає ключа шифрування, ви можете запустити `main.py` без нього та обрати пункт меню **[9]** для генерації нового надійного ключа, після чого вставити його в `.env`.

### 4. Запуск інтерактивного меню

```bash
python main.py
```

## Пункти меню програми

- **[1] Список акаунтів:** показує зайняті та вільні слоти, активний акаунт, статус авторизації та відсотки використання квот (5h / weekly).
- **[2] Авторизація (вхід у слот):** відкриває вікно браузера для логіну в Google-акаунт та зберігає отримані cookies у зашифроване сховище.
- **[3] Встановити активний акаунт:** перемикає активний слот для запитів за замовчуванням.
- **[4] Оновити ліміти (Usage):** запитує свіжі дані про ліміти (квоти запитів і кредити) для обраного або всіх слотів.
- **[5] Одноразовий запит (Ask Gemini):** надсилає запит через активний акаунт або вибраний слот та виводить відповідь.
- **[6] Інтерактивний діалоговий чат:** запускає безперервну розмову з Gemini з підтримкою історії повідомлень (`start_chat()`). Для повернення в меню введіть `exit` або натисніть Enter на порожньому рядку.
- **[7] Налаштування проксі для слота:** встановлює або очищає проксі-сервер для конкретного слота.
- **[8] Видалити акаунт зі слота:** локально видаляє обліковий запис зі сховища (з підтвердженням).
- **[9] Генерація нового ключа шифрування:** генерує криптографічно стійкий рядок для `GEMINI_MANAGER_KEY`.
- **[0] Вихід із програми.**

## Робота зі сховищем та Docker

Файл `vault.bin` зберігається у підпапці `example/data/` (якщо не перевизначено через `GEMINI_MANAGER_HOME`).

### Перенесення на Docker-сервер

1. Створіть та наповніть сесіями `vault.bin` на локальній машині через `main.py`.
2. Скопіюйте файл на сервер у папку з вашим сервісом, наприклад у `./data/vault.bin`.
3. У `docker-compose.yml` змонтуйте папку `./data` як том із правами на запис (`:rw`), щоб оновлені Google cookies (ротація сесії) зберігалися назад:

```yaml
services:
  gemini-service:
    build: .
    environment:
      - GEMINI_MANAGER_KEY=${GEMINI_MANAGER_KEY}
      - GEMINI_MANAGER_HOME=/app/data
    volumes:
      - ./data:/app/data:rw
    restart: unless-stopped
```
