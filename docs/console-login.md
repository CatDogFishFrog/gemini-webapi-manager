# Вхід з консолі: сценарії та діагностика

`gemini-vault login-console SLOT` (або `gemini-vault login SLOT --console`, `AccountRegistry.login(slot, method="console")`)
виконує вхід у Google повністю з терміналу. Програма запускає headless-браузер, відкриває сторінку входу й переносить
запитання Google в термінал.

## Що потрібно

- Пакет із extra: `pip install "gemini-vault[login]"`.
- Chromium: системний Chrome/Chromium (шлях — `--browser-path` або `GEMINI_VAULT_BROWSER_PATH`) або Chromium від
  Patchright: `gemini-vault install-browser` (на голому сервері — `install-browser --with-deps`, потрібен root).
  Під root Chromium запускається з `--no-sandbox`.
- Ключ `GEMINI_MANAGER_KEY`.

## Що відбувається в терміналі

| Крок Google | Що робить програма |
| --- | --- |
| E-mail | бере з `--email` або питає |
| Пароль | питає без відлуння; `!` — обрати інший спосіб входу |
| Вибір методу підтвердження | показує нумерований список зі сторінки (код з Authenticator, SMS, підтвердження на телефоні, резервний код…) |
| Код | питає без відлуння; `!` — інший метод, якщо сторінка його пропонує |
| Підтвердження на телефоні | показує число зі сторінки й чекає |
| Номер телефону, резервна пошта | питає (видимий ввід) |
| Екрани згоди | показує кнопки меню |
| CAPTCHA | зберігає знімок у debug-теку, просить ввести текст з картинки |
| Невідома сторінка | показує меню кнопок; знімок і опис сторінки зберігаються в debug-теку |

Захист від блокування: після 3 хибних паролів або 4 хибних кодів вхід припиняється. `q` у списку методів скасовує вхід.

## Параметри

`--email`, `--proxy URL`, `--browser-path`, `--headed` (показати вікно; потрібен дисплей), `--timeout` (час бездіяльності, типово
900 с), `--no-verify` (не перевіряти сесію в Gemini перед збереженням), `--replace` (замінити акаунт у зайнятому слоті,
зберігши його проксі й статус активного), `--debug-dir DIR`.

## Діагностика

`--debug-dir ./gemini-login-debug` записує для кожного кроку `NN-<крок>.png` і `NN-<крок>.json`. У JSON лежить
опис видимих полів, кнопок, варіантів і тексти помилок; значення полів не читаються, e-mail маскується, пароль і коди
не потрапляють ні в журнал, ні в файли. Невпізнана сторінка зберігається автоматично.

| Повідомлення | Що робити |
| --- | --- |
| `LoginBlockedError` (`/signin/rejected`, «браузер може бути небезпечним») | Google відхилив автоматизований вхід. Увійдіть на звичайному комп'ютері (`gemini-vault login SLOT` або `scripts/manage-vault.ps1`) і перенесіть `vault.bin` на сервер |
| `LoginChallengeError` | сторінка, яку програма не вміє проходити; `debug_dir` у повідомленні вказує, де лежать знімок і опис |
| `LoginTimeoutError` | не було відповіді довше за `--timeout`; повторіть вхід |
| `LoginAbortedError` | скасовано (`Ctrl+C`, `q`, порожня відповідь) |
| `SlotOccupiedError` | слот зайнятий: `remove` або `--replace` |
| `DuplicateAccountError` | цей e-mail уже підключено в іншому слоті |
| `Patchright is not installed` | `pip install "gemini-vault[login]"` |
| `Could not start the browser` | перевірте `GEMINI_VAULT_BROWSER_PATH` або `install-browser` |

CAPTCHA й антифрод Google програма не обходить: CAPTCHA розв'язує людина.
